2. Verifiable Codebase

Hollow is developed openly with standalone build verification scripts (./build.sh) and automated test suites in Swift verifying:

  • URL parsing and automatic HTTPS prefixing
  • Clean search query dispatching without middleman redirects
  • Local JSON persistence for bookmarks and history
  • Memory limits and isolated tab lifecycles

3. Third-Party Infrastructure

Hollow releases are distributed via standard Apple Disk Images (.dmg) hosted on authenticated content networks. Release manifests and updates are documented transparently on our versions portal.
